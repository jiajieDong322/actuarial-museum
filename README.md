# 精算陈列馆 · The Actuarial Cabinet

二十件可交互的精算展品，四座展厅，零依赖，双击即开。

**打开方式**：双击 `index.html`。不需要服务器、不需要联网、不需要装任何东西。

---

## 一、这是什么

不是讲义，是**能拖的公式**。每件展品有一个实时计算的图表和若干滑块——拖动参数，数字和曲线当场变形，旁边写着该看什么、容易错在哪、这套东西是怎么来的。

覆盖 IFoA **CS1 / CM1** 的主干：利息理论、生存模型、生命年金与寿险、风险理论。

| 展厅 | 展品 |
|---|---|
| 一 · 利息理论 | 01 累积与折现 · 02 利息力 · 03 净现值与内部收益率 · 04 年金现值 · 05 付款频率 · 06 永续年金 · 07 时间加权 vs 金额加权 |
| 二 · 生存模型 | 08 Gompertz 死亡力 · 09 生命表 · 10 预期余命 · 11 分数年龄假设 |
| 三 · 生命年金与寿险 | 12 终身寿险 · 13 定期寿险与两全 · 14 生命年金 · 15 净保费原理 · 16 前瞻准备金 |
| 四 · 风险理论 | 17 保费原理 · 18 聚合风险模型 · 19 破产概率与 Lundberg 界 · 20 VaR 与 TVaR |

## 二、目录结构

```
index.html                  外壳
assets/app.css              设计令牌 + 全部样式
js/math.js                  全部公式（唯一真源，纯函数）
js/charts.js                手写 SVG：折线 / 柱 / 直方 / 阴影带 / 参考线
js/core.js                  注册表、路由、滑块绑定、KPI 渲染、滚动高亮
js/content.js               展品文案（由 tools/build_content.py 生成）
js/exhibits/hall{1..4}-*.js 20 件展品的控件、KPI、图表定义
tools/                      参考实现与验收脚本
content/overrides.json      对 AI 初稿文案的修正 + 修正理由
```

**为什么是传统 `<script src>` 而不是 ES module**：`file://` 下 module 和 fetch 会被 CORS 拦死，双击就打不开。

## 四、内容来源与审校记录

20 篇文案由 4 个并行子 agent 起草，主脑做过**两轮**复核。所有修正连同理由记在 `content/overrides.json`（每条都能追到具体数值）。

### 第一轮：与模型行为不符

1. **08 常见误解** —— 原句自相矛盾（先说不该把 B 当具体年龄的死亡率，又说它等于 x=0 处的值）。
2. **10 一句话** —— 原文「余命先降后升的钩子形」在本模型下**不成立**。Gompertz 单律的 e_x 严格单调下降，没有钩子。
3. **12 一句话** —— 原文「保费就是死亡力与利息力的比值」错了，Ā_x = μ/(μ+δ) 是**和**作分母。
4. **07 公式** —— 原第一条 TWRR 写成了三年累计收益（漏了开三次方），与同组第三条自相矛盾。
5. **17 公式** —— 原四条用教科书的原始形式，但本页 α 已按均值归一，读者手算会和图上对不上。

### 第二轮：精算专业审校（逐条数值验证）

把 20 件展品的全部教学文字（含动态批注、图表标签）导出成 `content/review-dump.md` 后逐句核对。**6 处是断言与实测不符**，不是文风问题：

| 展品 | 原文断言 | 实测 |
|---|---|---|
| 12 | 常力闭式贴近真实值，「是合理近似」 | 0.2136 vs 真实 0.4426，**差 2.07 倍** |
| 13 | 两全险「几乎是条平线」 | 从 0.9516 **单调跌到** 0.4426 |
| 20 | 抬置信水平，TVaR 与 VaR 差距「迅速拉大」 | 比值 1.216 → 1.118，**方向相反** |
| 10 | 预期死亡年龄「只挪 0.02 岁」 | x=0 时 0.017，**x=40 时 0.255，x=80 时 0.883** |
| 05 | i⁽²⁾「比 i/2 略大」 | i=5% 时 4.94%，是 i/2 的 **1.98 倍** |
| 19 | 加载减半「风险远不止翻倍」 | ψ(0) 只涨 5%，放大 1.8 倍只发生在高盈余段 |

另有 **8 处文字描述了界面上不存在的行为**：拖动只移动标点的滑块却说「曲线下滑」（08/10）、说「拖动 t」（16 没有 t 滑块）、说「拉保费率 c」（19 的 c 由 θ 推出）、说「曲线高亮」（11 只是标点跳转）、拿「常力近似」当基准（12）、说「两全=平线」（13）、把 17 的斜率顺序说反（标准差原理最快，不是指数原理）。

### 第三轮：四路独立复核

主脑过完后，又把 `content/review-dump.md` 分给 4 个子 agent 各审一个展厅做交叉复核。它们又抓出 **6 处主脑漏掉的**，全部经主脑重算确认成立：

| 展品 | 漏掉的问题 | 实测 |
|---|---|---|
| 05 | 「利率越高，各付款频率的差距越收窄」 | 相对差 i=3% 时 1.49%，i=20% 时 **9.70%**——越拉越开，方向反了 |
| 05 | i⁽²⁾ 与 i/2 的比较**量纲不一致** | i⁽²⁾ 是年名义利率、i/2 是半年期利率；真正的半年期利率 (1+i)^(1/2)−1=2.47% |
| 12 | KPI 标签「每 1 元保额的保费」 | 数值 442.55 其实是**每 1000 元**，标签与数值差 1000 倍 |
| 14 | x 轴写「保证给付年限」 | ā_{x:n} 是定期生命年金，n 是任期；「保证期」属确定年金概念，用错术语 |
| 16 | 准备金公式**缺上标 1** | 无上标的 Ā_{x:n} 是两全保险，其 V_n=1，与同页「V_n=0」直接矛盾 |
| 20 | 「位置参数只平移曲线」 | 本页对数正态 σ 由均值与标准差反解，均值一抬形状就变：σ 从 0.703 掉到 0.080 |

另有 2 处低严重度：15 的「年缴」在连续缴费模型下不成立（改为「年缴费率（连续）」）、20 的导览把「损失超过 VaR」写成了「跌破分位数」。

修法分两类：文案改写进 `overrides.json`；文字承诺了但屏幕上没有的读数（14 的 Ā+δā=1、15 的期初损失期望）**在代码里补了 KPI**，让断言可见可查。

### 顺带修掉的实现/呈现错误

- **指数保费原理**最初把对数正态的「对数均值」当保费输出，量纲完全不对；已改为按变异系数归一的形式，并在参考实现里加了对 `(1/α)·ln E[e^{αX}]` 的独立断言。
- **KPI 标签用了 `text-transform: uppercase`**，把 δ 渲染成 Δ、v^n 渲染成 v^N、x 渲染成 X——精算记号全被改错。已移除。
- **16 的公式块混用了离散 A 与连续 ā**，量纲不一致；已统一为连续型。
- **19 的公式块没写适用前提**，把指数索赔下的精确式与一般分布的 Lundberg 界并称；已补上两行区分。

### 一次需要知道的文件篡改

审校过程中发现，本项目有 **7 处 `overrides.json` 条目和 4 处 `hall2/hall3` 的默认参数（基准死亡力 B 从 0.0003 被改成 0.00003）并非由我写入**，且没有对应的提交记录。B 被改成 1/10 会让第二、三展厅的全部数值偏离文档，而自动验收（只比固定参数点）**查不出来**。

已全部改回，并在 `tools/verify_math.js` 里新增一条**默认参数一致性检查**：同一个人口学参数（B / c / x / δ）在所有展品里必须是同一个默认值，不一致直接判 V3 失败。改动 `content/overrides.json` 时请保留 `_理由`，否则下次无法判断某条修正是有意还是意外。

## 五、已知局限

- 生命模型是 **Gompertz 单一死力律**，不含婴儿死亡率与灾难性死亡率，所以生存曲线比真实生命表"干净"。
- 生命寿险全部为**连续型**模型，未做离散（年缴/月缴）版本；只有 01–07 展品涉及离散年金。
- 19 展品的破产概率是**指数索赔下的精确式**，换任何其他索赔分布它就只是上界。
- 参数是教学设定，**不是真实经验生命表或市场数据**，不能直接用于定价。
- 未做深色模式、未做键盘全站导航、未做打印样式。

## 六、怎么改

- 加一件展品：在对应 `js/exhibits/hall*.js` 里 `MUSEUM.add({...})`，并在 `tools/reference.py` 的 `build_expected()` 里加一个对照点。
- 改公式：**只改 `js/math.js`**，然后同步 `tools/reference.py`，跑 `python tools/verify.py`。两边不一致就会立刻红。
- 改文案：改 `js/content.js`（会提示先读全文）；或改 `content/overrides.json` 后重跑 `python tools/build_content.py`。
